# Contributing to JobPulse

Thank you for your interest in contributing to **JobPulse**!

## Development Workflow

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/T14Z-x/jobpulse-tracker.git
   cd jobpulse-tracker
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Before opening a Pull Request, verify that TypeScript compiles cleanly:
   ```bash
   npx tsc --noEmit
   ```
